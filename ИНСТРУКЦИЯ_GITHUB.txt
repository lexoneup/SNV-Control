СНВ Контроль — инструкция для GitHub Pages

1. Распакуйте архив на iPhone через приложение «Файлы».
2. В GitHub создайте репозиторий snv-control. Для GitHub Pages он может быть Public; не загружайте в репозиторий рабочие данные или резервные копии.
3. В репозитории нажмите Add file → Upload files и загрузите ВСЕ файлы из архива в корень репозитория (не загружайте ZIP вместо файлов).
4. Нажмите Commit changes.
5. Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, branch main, folder /(root), нажмите Save.
6. Дождитесь публикации, затем откройте URL вида https://ВАШ-ЛОГИН.github.io/snv-control/ в Safari.
7. Для установки нажмите «Поделиться» → «На экран Домой». Запустите приложение с новой иконки, пока есть интернет, и подождите немного, чтобы файлы закэшировались.
8. Проверьте: создайте тестовую станцию и два счётчика, закройте приложение, включите авиарежим и откройте с иконки. Проверьте, что станции видны и расчёт работает. После проверки удалите тестовые данные.
9. Для каждой станции добавьте столько счётчиков СНВ, сколько нужно. У каждого счётчика своя дата и показание, своя история и независимые расчёты.
10. При замене счётчика откройте станцию → Изменить у нужного СНВ, введите дату и начальное показание нового прибора. Это создаёт новую точку отсчёта для будущих расчётов; старые записи истории сохраняются.
11. На вкладке «Данные» делайте «Экспортировать JSON» и сохраняйте копию в приложении «Файлы»/iCloud Drive. Для восстановления нажмите «Импортировать копию». Импорт заменяет текущую базу.
12. Не очищайте данные сайта Safari и не удаляйте веб-приложение без резервной копии. На iPhone офлайн-кэш и локальные данные могут быть удалены системой или пользователем; резервная копия обязательна.

Расчёт: новое показание = последнее сохранённое показание + 24 × число календарных суток между датами. Предполагается непрерывная наработка 24 часа в сутки.
